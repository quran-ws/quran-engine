How it works

A letter layer is an optional file for each page, NNN.qvl. With it the engine knows the letters of each word and the paths that draw them. Where one outline joins two letters, the layer holds the outline cut into pieces.

letter colours the body and dots of the letter under the tap. mark colours the mark under the tap, or all the marks of a letter when the tap is on its body. A layer attaches only to the page file it was built with.

How it works

Leading only grows: the printed line spacing is the floor, so the lines never close up, and the text width is always the viewport's. The controls spend the empty paper that a tall screen leaves above and below the printed page.

With the native frame off, the host draws its own around the boxes that page.surahHeadersView() reports: one for the frame, one for the title ink. This mushaf's artwork carries no frame yet, so only the host frame shows.

How it works

The page keeps the viewport width and the ink grows: fewer words fit a row, the rest move down, and the page scrolls. Words are never reshaped, an ayah keeps its medallion, and a surah banner keeps a row of its own.

Size. The steps a reader gets instead of a free zoom. The rows only rearrange at certain zooms, so the engine searches a band around each step for the zoom whose rows come out best on this page. The sizes differ a little from page to page for that reason.

Pinch. What two fingers do to the page. Stepped is what a reader gets: the pinch lands on one of the sizes and the page breaks its rows again. Free reflows to whatever the fingers ask for. Magnify scales the printed page and leaves every row where the print has it.

Relax. Relaxing gives a row's gaps a share of the space it has left over, so the emptier a row is the more it opens. The gap cap bounds that: a row of few words has few gaps and so opens less, whatever the slider says.
