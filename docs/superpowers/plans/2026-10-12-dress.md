**Goal:** Dress a page in another mushaf's ornaments: a QVO1 ornament set, a converter from `quran-ws/quran-assets`, placement in the core through the layout's placements, a C ABI, and a web binding with a demo.

**Architecture:** `qvp-format::ornaments` reads and writes the set. `qvp-convert ornaments` builds one from the catalogue. `qvp-core::dress` places up to three ornaments on a page from `ayah_marks()`, `surah_headers()` and the laid-out page box, and hands back a display list whose draws carry placement indices. `qvp-ffi` exposes ten symbols. `web/qvp.js` binds them and paints the layer behind the ink.

**Tech Stack:** Rust 2021 (no new crates), the existing `roxmltree` and `svgtypes` in `qvp-convert`, wasm32 for the web, plain JavaScript.

**Spec:** `docs/superpowers/specs/2026-10-12-dress-design.md`

```rust
//! QVO1: an ornament set. The ayah medallions, surah bands and page frames of other
//! printed mushafs and fonts, converted from the `quran-ws/quran-assets` catalogue so
//! the engine can dress a page in them without an XML parser at runtime.
//!
//! One file holds many ornaments, one per catalogue asset. An ornament carries its
//! kind, style, lineage, riwayah, licence, palette and one asset. A page frame that
//! tiles also carries the corner and the two repeat units it is assembled from.
//!
//! Outlines are in the asset's own viewBox units, quantised by `quant`. Placement is
//! the engine's job, not the file's.
use crate::{cmds_bbox, decode_cmds, encode_cmds, read_varint, unzigzag, write_varint, zigzag, Cmd, Error, IBox};

pub const ORNAMENTS_MAGIC: &[u8; 4] = b"QVO1";
/// 1/1000 of an asset unit. Assets are 100 units tall and a frame slice is about 6
/// units across, so the page's 1/100 would be coarse.
pub const ORNAMENT_QUANT: u16 = 1000;

/// Which piece of page furniture an ornament replaces.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
#[repr(u8)]
pub enum OrnamentKind {
    /// The ring around an ayah number (`ayah-markers` in the catalogue).
    AyahMark = 0,
    /// The band a surah name is printed in (`surah-headers`).
    SurahHeader = 1,
    /// The border around the text area (`page-frames`).
    PageFrame = 2,
}

impl OrnamentKind {
    pub fn from_u8(v: u8) -> Option<Self> {
        match v {
            0 => Some(Self::AyahMark),
            1 => Some(Self::SurahHeader),
            2 => Some(Self::PageFrame),
            _ => None,
        }
    }
    pub fn as_str(self) -> &'static str {
        match self {
            Self::AyahMark => "ayah_mark",
            Self::SurahHeader => "surah_header",
            Self::PageFrame => "page_frame",
        }
    }
    /// The catalogue's name for the same thing.
    pub fn catalog_type(self) -> &'static str {
        match self {
            Self::AyahMark => "ayah-markers",
            Self::SurahHeader => "surah-headers",
            Self::PageFrame => "page-frames",
        }
    }
    pub const ALL: [OrnamentKind; 3] = [Self::AyahMark, Self::SurahHeader, Self::PageFrame];
}

/// Where the artwork came from.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
#[repr(u8)]
pub enum Lineage {
    /// Traced from a scan of a printed mushaf.
    Scan = 0,
    /// Taken from a glyph of a font.
    Font = 1,
}

impl Lineage {
    pub fn from_u8(v: u8) -> Option<Self> {
        match v {
            0 => Some(Self::Scan),
            1 => Some(Self::Font),
            _ => None,
        }
    }
    pub fn as_str(self) -> &'static str {
        match self {
            Self::Scan => "scan",
            Self::Font => "font",
        }
    }
}

/// One printed colour of a design. Every outline belongs to exactly one.
///
/// `slot` is the transparent window the design leaves for the thing it frames. It has
/// no colour of its own.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Part {
    pub name: String,
    /// 0xRRGGBBAA; alpha 0 when the design leaves it open.
    pub color: u32,
    /// Painted as a stroke rather than a fill (the `line` part).
    pub stroke: bool,
}

pub const OPF_EVENODD: u8 = 1;
pub const OPF_STROKE: u8 = 2;

/// One outline of an asset, in the asset's own units, quantised.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct OrnamentPath {
    /// Index into [`Ornament::parts`].
    pub part: u16,
    pub flags: u8,
    /// Stroke width in quantised asset units (0 when filled).
    pub stroke_width: i32,
    pub op_off: u32,
    pub op_len: u32,
    pub bbox: IBox,
}

/// A drawing with its own viewBox, and the window it leaves open.
#[derive(Clone, Debug, Default, PartialEq)]
pub struct Asset {
    /// `x, y, w, h` of the viewBox, in asset units (not quantised).
    pub view_box: [f32; 4],
    /// The catalogue's slot: the number box, the name box or the text area, in the
    /// same units.
    pub slot: Option<[f32; 4]>,
    pub first_path: u32,
    pub n_paths: u32,
}

impl Asset {
    pub fn width(&self) -> f32 {
        self.view_box[2]
    }
    pub fn height(&self) -> f32 {
        self.view_box[3]
    }
    /// The centre of the slot, or of the viewBox when the asset has no slot.
    pub fn slot_centre(&self) -> (f32, f32) {
        let b = self.slot.unwrap_or(self.view_box);
        (b[0] + b[2] / 2.0, b[1] + b[3] / 2.0)
    }
}

/// How a page frame is assembled when it tiles: one corner and two repeat units.
///
/// Stretching one drawing onto a page of a different aspect makes the side borders
/// fatter than the top and bottom. Keeping the corner and repeating only the straight
/// run does not.
#[derive(Clone, Debug, PartialEq)]
pub struct Slices {
    pub corner_w: f32,
    pub corner_h: f32,
    pub repeat_h: f32,
    pub repeat_v: f32,
    /// The other three corners are 180° turned copies rather than mirrored ones.
    pub rotate: bool,
    pub corner: Asset,
    pub edge_h: Asset,
    pub edge_v: Asset,
}

/// What the artwork may be redistributed under. It travels with the file so a host can
/// say so on screen.
#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct License {
    pub id: String,
    /// "confirmed", "provisional" or "pending".
    pub status: String,
    /// True when the status is "confirmed".
    pub redistributable: bool,
    pub attribution: String,
}

/// One catalogue asset: a kind, a style and one drawing.
#[derive(Clone, Debug, PartialEq)]
pub struct Ornament {
    pub kind: OrnamentKind,
    /// The catalogue's style key, e.g. "mushaf-qalon" or "font-003-regular".
    pub style: String,
    pub lineage: Lineage,
    /// The riwayah the mushaf prints; empty for a font.
    pub riwayah: String,
    pub license: License,
    /// The palette, in printing order.
    pub parts: Vec<Part>,
    pub asset: Asset,
    /// Only a page frame that tiles has these.
    pub slices: Option<Slices>,
}

impl Ornament {
    pub fn part_index(&self, name: &str) -> Option<u16> {
        self.parts.iter().position(|p| p.name == name).map(|i| i as u16)
    }
}

/// A whole ornament set: many ornaments sharing one outline pool.
#[derive(Clone, Debug, PartialEq)]
pub struct OrnamentSet {
    pub quant: u16,
    pub ornaments: Vec<Ornament>,
    pub paths: Vec<OrnamentPath>,
    pub ops: Vec<u8>,
}

impl Default for OrnamentSet {
    fn default() -> Self {
        OrnamentSet { quant: ORNAMENT_QUANT, ornaments: vec![], paths: vec![], ops: vec![] }
    }
}

impl OrnamentSet {
    /// The index of the ornament of `kind` in `style`.
    pub fn find(&self, kind: OrnamentKind, style: &str) -> Option<usize> {
        self.ornaments.iter().position(|o| o.kind == kind && o.style == style)
    }
    pub fn path_cmds(&self, i: usize) -> Result<Vec<Cmd>, Error> {
        let p = self.paths.get(i).ok_or(Error::Corrupt("ornament path index"))?;
        let end = (p.op_off + p.op_len) as usize;
        let ops = self.ops.get(p.op_off as usize..end).ok_or(Error::Truncated("ornament ops"))?;
        decode_cmds(ops, 0, 0)
    }
    /// Append one outline; returns its index.
    pub fn push_path(&mut self, part: u16, flags: u8, stroke_width: i32, cmds: &[Cmd]) -> u32 {
        let op_off = self.ops.len() as u32;
        let bbox = encode_cmds(cmds, 0, 0, &mut self.ops);
        let op_len = self.ops.len() as u32 - op_off;
        self.paths.push(OrnamentPath { part, flags, stroke_width, op_off, op_len, bbox });
        (self.paths.len() - 1) as u32
    }

    pub fn encode(&self) -> Vec<u8> {
        let mut o = Vec::with_capacity(64 * 1024);
        o.extend_from_slice(ORNAMENTS_MAGIC);
        o.extend_from_slice(&self.quant.to_le_bytes());
        write_varint(&mut o, self.ornaments.len() as u32);
        for orn in &self.ornaments {
            o.push(orn.kind as u8);
            o.push(orn.lineage as u8);
            put_str(&mut o, &orn.style);
            put_str(&mut o, &orn.riwayah);
            put_str(&mut o, &orn.license.id);
            put_str(&mut o, &orn.license.status);
            write_varint(&mut o, orn.license.redistributable as u32);
            put_str(&mut o, &orn.license.attribution);
            write_varint(&mut o, orn.parts.len() as u32);
            for p in &orn.parts {
                put_str(&mut o, &p.name);
                o.extend_from_slice(&p.color.to_le_bytes());
                write_varint(&mut o, p.stroke as u32);
            }
            put_asset(&mut o, &orn.asset);
            match &orn.slices {
                Some(sl) => {
                    write_varint(&mut o, 1);
                    for v in [sl.corner_w, sl.corner_h, sl.repeat_h, sl.repeat_v] {
                        o.extend_from_slice(&v.to_le_bytes());
                    }
                    write_varint(&mut o, sl.rotate as u32);
                    put_asset(&mut o, &sl.corner);
                    put_asset(&mut o, &sl.edge_h);
                    put_asset(&mut o, &sl.edge_v);
                }
                None => write_varint(&mut o, 0),
            }
        }
        write_varint(&mut o, self.paths.len() as u32);
        for p in &self.paths {
            write_varint(&mut o, p.part as u32);
            o.push(p.flags);
            write_varint(&mut o, zigzag(p.stroke_width));
            write_varint(&mut o, p.op_off);
            write_varint(&mut o, p.op_len);
        }
        write_varint(&mut o, self.ops.len() as u32);
        o.extend_from_slice(&self.ops);
        o
    }

    pub fn decode(b: &[u8]) -> Result<OrnamentSet, Error> {
        if b.len() < 6 || &b[0..4] != ORNAMENTS_MAGIC {
            return Err(Error::BadMagic);
        }
        let quant = u16::from_le_bytes([b[4], b[5]]);
        if quant == 0 {
            return Err(Error::Corrupt("ornament quant"));
        }
        let mut pos = 6;
        let n = read_varint(b, &mut pos)? as usize;
        let mut ornaments = Vec::with_capacity(n.min(4096));
        for _ in 0..n {
            let kind = OrnamentKind::from_u8(get_u8(b, &mut pos)?).ok_or(Error::Corrupt("ornament kind"))?;
            let lineage = Lineage::from_u8(get_u8(b, &mut pos)?).ok_or(Error::Corrupt("ornament lineage"))?;
            let style = get_str(b, &mut pos)?;
            let riwayah = get_str(b, &mut pos)?;
            let license = License {
                id: get_str(b, &mut pos)?,
                status: get_str(b, &mut pos)?,
                redistributable: read_varint(b, &mut pos)? != 0,
                attribution: get_str(b, &mut pos)?,
            };
            let n_parts = read_varint(b, &mut pos)? as usize;
            let mut parts = Vec::with_capacity(n_parts.min(256));
            for _ in 0..n_parts {
                let name = get_str(b, &mut pos)?;
                let color = get_u32(b, &mut pos)?;
                parts.push(Part { name, color, stroke: read_varint(b, &mut pos)? != 0 });
            }
            let asset = get_asset(b, &mut pos)?;
            let slices = if read_varint(b, &mut pos)? != 0 {
                let mut f = [0f32; 4];
                for v in f.iter_mut() {
                    *v = get_f32(b, &mut pos)?;
                }
                let rotate = read_varint(b, &mut pos)? != 0;
                Some(Slices { corner_w: f[0], corner_h: f[1], repeat_h: f[2], repeat_v: f[3], rotate, corner: get_asset(b, &mut pos)?, edge_h: get_asset(b, &mut pos)?, edge_v: get_asset(b, &mut pos)? })
            } else {
                None
            };
            ornaments.push(Ornament { kind, style, lineage, riwayah, license, parts, asset, slices });
        }
        let n_paths = read_varint(b, &mut pos)? as usize;
        let mut paths = Vec::with_capacity(n_paths.min(1 << 20));
        for _ in 0..n_paths {
            let part = read_varint(b, &mut pos)? as u16;
            let flags = get_u8(b, &mut pos)?;
            let stroke_width = unzigzag(read_varint(b, &mut pos)?);
            let op_off = read_varint(b, &mut pos)?;
            let op_len = read_varint(b, &mut pos)?;
            paths.push(OrnamentPath { part, flags, stroke_width, op_off, op_len, bbox: IBox::EMPTY });
        }
        let n_ops = read_varint(b, &mut pos)? as usize;
        let ops = b.get(pos..pos + n_ops).ok_or(Error::Truncated("ornament ops"))?.to_vec();
        let mut set = OrnamentSet { quant, ornaments, paths, ops };
        for i in 0..set.paths.len() {
            let bb = cmds_bbox(&set.path_cmds(i)?);
            set.paths[i].bbox = bb;
        }
        Ok(set)
    }
}

fn put_str(o: &mut Vec<u8>, s: &str) {
    write_varint(o, s.len() as u32);
    o.extend_from_slice(s.as_bytes());
}

fn put_asset(o: &mut Vec<u8>, a: &Asset) {
    for v in a.view_box {
        o.extend_from_slice(&v.to_le_bytes());
    }
    match a.slot {
        Some(s) => {
            write_varint(o, 1);
            for v in s {
                o.extend_from_slice(&v.to_le_bytes());
            }
        }
        None => write_varint(o, 0),
    }
    write_varint(o, a.first_path);
    write_varint(o, a.n_paths);
}

fn get_u8(b: &[u8], pos: &mut usize) -> Result<u8, Error> {
    let v = *b.get(*pos).ok_or(Error::Truncated("ornament byte"))?;
    *pos += 1;
    Ok(v)
}

fn get_str(b: &[u8], pos: &mut usize) -> Result<String, Error> {
    let len = read_varint(b, pos)? as usize;
    let s = b.get(*pos..*pos + len).ok_or(Error::Truncated("ornament string"))?;
    *pos += len;
    Ok(std::str::from_utf8(s).map_err(|_| Error::Corrupt("utf8"))?.to_owned())
}

fn get_u32(b: &[u8], pos: &mut usize) -> Result<u32, Error> {
    let s = b.get(*pos..*pos + 4).ok_or(Error::Truncated("ornament u32"))?;
    *pos += 4;
    Ok(u32::from_le_bytes([s[0], s[1], s[2], s[3]]))
}

fn get_f32(b: &[u8], pos: &mut usize) -> Result<f32, Error> {
    Ok(f32::from_bits(get_u32(b, pos)?))
}

fn get_asset(b: &[u8], pos: &mut usize) -> Result<Asset, Error> {
    let mut view_box = [0f32; 4];
    for v in view_box.iter_mut() {
        *v = get_f32(b, pos)?;
    }
    let slot = if read_varint(b, pos)? != 0 {
        let mut s = [0f32; 4];
        for v in s.iter_mut() {
            *v = get_f32(b, pos)?;
        }
        Some(s)
    } else {
        None
    };
    Ok(Asset { view_box, slot, first_path: read_varint(b, pos)?, n_paths: read_varint(b, pos)? })
}

```rust
//! `quran-assets` catalogue to QVO. Reads a checkout of `quran-ws/quran-assets`
//! (`catalog.json`, schema `quran-assets/catalog@1`, and the colour SVG of every asset)
//! and writes one ornament set the engine loads without an XML parser.
//!
//! The catalogue calls the three asset types `ayah-markers`, `surah-headers` and
//! `page-frames`. The engine's own names are `ayah_mark`, `surah_header` and
//! `page_frame`.
//!
//! Nothing about the artwork changes. `<use>` instances are expanded (an asset draws
//! one half and mirrors it, and ids are file-local), transforms are flattened into
//! asset units, and each outline keeps the part its `data-part` names. The palette is
//! the catalogue's, in its order; a part the SVG draws and the palette lacks is added
//! after it with the SVG's own colour.
use crate::affine::Affine;
use crate::json::Json;
use qvp_format::ornaments::*;
use qvp_format::{Cmd, IBox};
use roxmltree::Node;
use std::collections::HashMap;
use std::path::Path;

#[derive(Clone, Debug, Default)]
pub struct BuildOptions {
    /// Only these styles; empty takes every style the catalogue lists.
    pub styles: Vec<String>,
    /// Only assets whose licence status is `confirmed`.
    pub redistributable_only: bool,
}

#[derive(Default)]
pub struct Report {
    pub warnings: Vec<String>,
    /// (style, kind, outlines) for each asset that made it in.
    pub assets: Vec<(String, &'static str, u32)>,
}

/// Build an ornament set from a catalogue directory. An asset the catalogue names but
/// does not deliver is a warning, not an error.
pub fn build(dir: &Path, opts: &BuildOptions) -> Result<(OrnamentSet, Report), String> {
    let catalog_path = dir.join("catalog.json");
    let bytes = std::fs::read(&catalog_path).map_err(|e| format!("{}: {e}", catalog_path.display()))?;
    let cat = Json::parse(&bytes).map_err(|e| format!("{}: {e}", catalog_path.display()))?;
    let assets = cat.get("assets").map(|a| a.arr()).unwrap_or(&[]);
    if assets.is_empty() {
        return Err(format!("{}: no assets", catalog_path.display()));
    }
    let mut set = OrnamentSet::default();
    let mut report = Report::default();
    for rec in assets {
        let style = rec.s("style");
        let Some(kind) = OrnamentKind::ALL.iter().copied().find(|k| k.catalog_type() == rec.s("type")) else {
            report.warnings.push(format!("{}: unknown type {:?}", rec.s("id"), rec.s("type")));
            continue;
        };
        if !opts.styles.is_empty() && !opts.styles.iter().any(|w| w == style) {
            continue;
        }
        let status = rec.s("license.status");
        let redistributable = status == "confirmed";
        if opts.redistributable_only && !redistributable {
            report.warnings.push(format!("{style}/{}: {status}, left out", kind.as_str()));
            continue;
        }
        let rel = rec.s("variants.color");
        if rel.is_empty() {
            report.warnings.push(format!("{style}/{}: no colour variant in the catalogue", kind.as_str()));
            continue;
        }
        let mut parts: Vec<Part> = rec
            .get("palette")
            .map(|p| p.arr())
            .unwrap_or(&[])
            .iter()
            .map(|p| Part { name: p.s("name").to_owned(), color: css_rgba(p.s("hex")), stroke: p.path("stroke").and_then(|v| v.bool()).unwrap_or(false) })
            .collect();
        let slot = rec.get("slots").and_then(|s| s.arr().first()).and_then(|s| Some([s.f("x")? as f32, s.f("y")? as f32, s.f("w")? as f32, s.f("h")? as f32]));
        // A tiled frame is assembled from its slices, so the whole drawing is dead
        // weight. Its viewBox and slot are still the measurement the border is placed
        // from, so the record stays and only the outlines go.
        let slices = if kind == OrnamentKind::PageFrame { read_slices(dir, rec, style, &mut set, &mut parts, &mut report) } else { None };
        let asset = match read_asset(&dir.join(rel), &mut set, &mut parts, slices.is_none(), slot) {
            Ok(a) => a,
            Err(e) => {
                report.warnings.push(format!("{style}/{}: {e}", kind.as_str()));
                continue;
            }
        };
        report.assets.push((style.to_owned(), kind.as_str(), asset.n_paths));
        set.ornaments.push(Ornament {
            kind,
            style: style.to_owned(),
            lineage: if rec.s("lineage") == "font" { Lineage::Font } else { Lineage::Scan },
            riwayah: rec.s("riwayah").to_owned(),
            license: License { id: rec.s("license.id").to_owned(), status: status.to_owned(), redistributable, attribution: rec.s("license.attribution").to_owned() },
            parts,
            asset,
            slices,
        });
    }
    if set.ornaments.is_empty() {
        return Err(format!("{}: nothing to build", catalog_path.display()));
    }
    Ok((set, report))
}

/// The corner and the two repeat units of a frame that tiles, when the catalogue
/// publishes them and all three read.
fn read_slices(dir: &Path, rec: &Json, style: &str, set: &mut OrnamentSet, parts: &mut Vec<Part>, report: &mut Report) -> Option<Slices> {
    let files = rec.path("slices.files").and_then(|v| v.obj())?;
    let mut slice = |key: &str| -> Result<Asset, String> {
        let p = files.get(key).and_then(|v| v.str()).ok_or_else(|| format!("slices.files has no {key:?}"))?;
        read_asset(&dir.join(p), set, parts, true, None)
    };
    let (a, b, c) = (slice("corner"), slice("edge-h"), slice("edge-v"));
    match (a, b, c) {
        (Ok(corner), Ok(edge_h), Ok(edge_v)) => Some(Slices {
            corner_w: rec.f("slices.corner.w").unwrap_or(corner.width() as f64) as f32,
            corner_h: rec.f("slices.corner.h").unwrap_or(corner.height() as f64) as f32,
            repeat_h: rec.f("slices.repeat.h").unwrap_or(edge_h.width() as f64) as f32,
            repeat_v: rec.f("slices.repeat.v").unwrap_or(edge_v.height() as f64) as f32,
            rotate: rec.s("slices.corner_mode") == "rotate",
            corner,
            edge_h,
            edge_v,
        }),
        (a, b, c) => {
            for e in [a, b, c].into_iter().filter_map(|r| r.err()) {
                report.warnings.push(format!("{style}/page_frame slices: {e}"));
            }
            report.warnings.push(format!("{style}/page_frame: no usable slices, the whole frame will be stretched"));
            None
        }
    }
}

/// Parse one asset SVG and append its outlines to `set`. With `geometry` off only the
/// viewBox and the slot are kept. `slot` is the catalogue's; the SVG's `data-slot` is
/// the fallback.
fn read_asset(path: &Path, set: &mut OrnamentSet, parts: &mut Vec<Part>, geometry: bool, slot: Option<[f32; 4]>) -> Result<Asset, String> {
    let text = std::fs::read_to_string(path).map_err(|e| format!("{}: {e}", path.display()))?;
    let doc = roxmltree::Document::parse(&text).map_err(|e| format!("{}: xml: {e}", path.display()))?;
    let root = doc.root_element();
    let view_box = numbers(root.attribute("viewBox").unwrap_or("")).ok_or_else(|| format!("{}: missing or bad viewBox", path.display()))?;
    let slot = slot.or_else(|| numbers(root.attribute("data-slot").unwrap_or("")));
    let mut by_id: HashMap<&str, Node> = HashMap::new();
    for n in root.descendants().filter(|n| n.is_element()) {
        if let Some(id) = n.attribute("id") {
            by_id.entry(id).or_insert(n);
        }
    }
    let first_path = set.paths.len() as u32;
    if geometry {
        let mut cx = AssetCtx { quant: set.quant as f64, set, parts, by_id, depth: 0 };
        cx.walk(root, Affine::IDENTITY, &Paint::default()).map_err(|e| format!("{}: {e}", path.display()))?;
    }
    Ok(Asset { view_box, slot, first_path, n_paths: set.paths.len() as u32 - first_path })
}

fn numbers(s: &str) -> Option<[f32; 4]> {
    let v: Vec<f32> = s.split([' ', ',', '\t', '\n']).filter(|t| !t.is_empty()).filter_map(|t| t.parse().ok()).collect();
    (v.len() == 4).then(|| [v[0], v[1], v[2], v[3]])
}

/// Inherited paint state while walking an asset.
#[derive(Clone, Default)]
struct Paint {
    part: Option<u16>,
    stroke: bool,
    stroke_width: f64,
    evenodd: bool,
}

struct AssetCtx<'a, 'd, 'i> {
    set: &'a mut OrnamentSet,
    parts: &'a mut Vec<Part>,
    by_id: HashMap<&'d str, Node<'d, 'i>>,
    quant: f64,
    depth: u32,
}

impl<'a, 'd, 'i> AssetCtx<'a, 'd, 'i> {
    fn part_of(&mut self, name: &str, color: u32, stroke: bool) -> u16 {
        if let Some(i) = self.parts.iter().position(|p| p.name == name) {
            return i as u16;
        }
        self.parts.push(Part { name: name.to_owned(), color, stroke });
        (self.parts.len() - 1) as u16
    }

    fn walk(&mut self, n: Node<'d, 'i>, tf: Affine, paint: &Paint) -> Result<(), String> {
        if self.depth > 32 {
            return Err("nested <use> too deep".into());
        }
        for child in n.children().filter(|c| c.is_element()) {
            let tag = child.tag_name().name();
            if tag == "metadata" || tag == "title" || tag == "desc" {
                continue;
            }
            let local = match child.attribute("transform") {
                Some(t) => tf.then(&Affine::parse(t)?),
                None => tf,
            };
            let mut p = paint.clone();
            if let Some(name) = child.attribute("data-part") {
                let stroke_attr = child.attribute("stroke").filter(|v| *v != "none");
                let fill_attr = child.attribute("fill");
                let (color, is_stroke) = match stroke_attr {
                    Some(s) => (css_rgba(s), true),
                    None => (css_rgba(fill_attr.unwrap_or("#000000")), false),
                };
                p.stroke = is_stroke;
                p.part = Some(self.part_of(name, color, is_stroke));
            }
            if let Some(w) = child.attribute("stroke-width").and_then(|v| v.parse::<f64>().ok()) {
                p.stroke_width = w;
            }
            match child.attribute("fill-rule") {
                Some("evenodd") => p.evenodd = true,
                Some(_) => p.evenodd = false,
                None => {}
            }
            match tag {
                "use" => {
                    let href = child.attribute("href").or_else(|| child.attribute(("http://www.w3.org/1999/xlink", "href"))).unwrap_or("");
                    let Some(target) = href.strip_prefix('#').and_then(|id| self.by_id.get(id).copied()) else {
                        continue;
                    };
                    // An instance is the referenced element drawn again, so the element
                    // itself is walked, not only its children.
                    let inner = match target.attribute("transform") {
                        Some(t) => local.then(&Affine::parse(t)?),
                        None => local,
                    };
                    self.depth += 1;
                    self.walk_element(target, inner, &p)?;
                    self.depth -= 1;
                }
                "path" => self.emit_path(child, &local, &p)?,
                _ => self.walk(child, local, &p)?,
            }
        }
        Ok(())
    }

    /// Walk `n` itself as if it were a child: its own `data-part`, paint and `d` count.
    fn walk_element(&mut self, n: Node<'d, 'i>, tf: Affine, paint: &Paint) -> Result<(), String> {
        let mut p = paint.clone();
        if let Some(name) = n.attribute("data-part") {
            let stroke_attr = n.attribute("stroke").filter(|v| *v != "none");
            let (color, is_stroke) = match stroke_attr {
                Some(s) => (css_rgba(s), true),
                None => (css_rgba(n.attribute("fill").unwrap_or("#000000")), false),
            };
            p.stroke = is_stroke;
            p.part = Some(self.part_of(name, color, is_stroke));
        }
        if let Some(w) = n.attribute("stroke-width").and_then(|v| v.parse::<f64>().ok()) {
            p.stroke_width = w;
        }
        if n.tag_name().name() == "path" {
            return self.emit_path(n, &tf, &p);
        }
        self.walk(n, tf, &p)
    }

    fn emit_path(&mut self, n: Node<'d, 'i>, tf: &Affine, p: &Paint) -> Result<(), String> {
        let Some(d) = n.attribute("d") else { return Ok(()) };
        let Some(part) = p.part else { return Ok(()) };
        let cmds = parse_d(d, tf, self.quant)?;
        if cmds.is_empty() {
            return Ok(());
        }
        let mut flags = 0u8;
        if p.evenodd {
            flags |= OPF_EVENODD;
        }
        let width = if p.stroke {
            flags |= OPF_STROKE;
            // a stroke is drawn in the space the path is in, so the width travels
            // through the same transform
            (p.stroke_width * stroke_scale(tf) * self.quant).round() as i32
        } else {
            0
        };
        self.set.push_path(part, flags, width, &cmds);
        Ok(())
    }
}

fn stroke_scale(m: &Affine) -> f64 {
    (m.a * m.d - m.b * m.c).abs().sqrt()
}

fn parse_d(d: &str, tf: &Affine, quant: f64) -> Result<Vec<Cmd>, String> {
    let mut cmds = Vec::new();
    let q = |x: f64, y: f64| {
        let (px, py) = tf.apply(x, y);
        ((px * quant).round() as i32, (py * quant).round() as i32)
    };
    for seg in svgtypes::SimplifyingPathParser::from(d) {
        let seg = seg.map_err(|e| format!("path d: {e}"))?;
        use svgtypes::SimplePathSegment as S;
        cmds.push(match seg {
            S::MoveTo { x, y } => {
                let (x, y) = q(x, y);
                Cmd::MoveTo(x, y)
            }
            S::LineTo { x, y } => {
                let (x, y) = q(x, y);
                Cmd::LineTo(x, y)
            }
            S::Quadratic { x1, y1, x, y } => {
                let (x1, y1) = q(x1, y1);
                let (x, y) = q(x, y);
                Cmd::QuadTo(x1, y1, x, y)
            }
            S::CurveTo { x1, y1, x2, y2, x, y } => {
                let (x1, y1) = q(x1, y1);
                let (x2, y2) = q(x2, y2);
                let (x, y) = q(x, y);
                Cmd::CubicTo(x1, y1, x2, y2, x, y)
            }
            S::ClosePath => Cmd::Close,
        });
    }
    Ok(cmds)
}

/// `#rgb`, `#rrggbb`, `none` to 0xRRGGBBAA. Anything else is opaque black.
fn css_rgba(s: &str) -> u32 {
    let t = s.trim();
    if t.eq_ignore_ascii_case("none") || t.is_empty() {
        return 0;
    }
    let h = t.strip_prefix('#').unwrap_or(t);
    let full = match h.len() {
        3 | 4 => h.chars().flat_map(|c| [c, c]).collect::<String>(),
        _ => h.to_owned(),
    };
    match full.len() {
        6 => u32::from_str_radix(&full, 16).map(|v| v << 8 | 0xff).unwrap_or(0x000000ff),
        8 => u32::from_str_radix(&full, 16).unwrap_or(0x000000ff),
        _ => 0x000000ff,
    }
}

    }

```rust
//! Dress a page in another mushaf's ornaments.
//!
//! The medallions, surah bands and page borders of other mushafs are not part of a QVP
//! page. They are an [`OrnamentSet`], and this module puts them on a page they were
//! never drawn for.
//!
//! Every ornament is placed from a measurement, never a fixed offset: the medallion
//! from the printed ring's centre and radius, the band from the surah title's box and
//! the text column, the border from the laid-out page box. That is why the same rules
//! land on all 604 pages.
//!
//! The result is a display list in page units. Each draw carries the placement index
//! the page's own draws carry, so a host applies the transform it already applies to
//! the ink. A host paints the list behind the page ink. Only the printed ring is
//! hidden; the numeral inside it is the print's own ink and stays on top.
use crate::style::Selector;
use crate::{Handle, Page, Rgba, NONE};
use qvp_format::ornaments::*;
use qvp_format::{Cmd, PathKind, OP_CLOSE, OP_CUBIC, OP_LINE, OP_MOVE, OP_QUAD};
use std::sync::Arc;

/// What to dress a page in: up to one ornament per kind.
#[derive(Clone, Debug, PartialEq)]
pub struct DressSpec {
    /// Index into [`OrnamentSet::ornaments`], or [`NONE`] for none.
    pub ayah_mark: u32,
    pub surah_header: u32,
    pub page_frame: u32,
    /// Air between the text and the border, in page units.
    pub gap: f32,
    /// Draw only the constant-width strokes: the same drawing with the fills taken
    /// away. One ink left means one colour.
    pub line_art: bool,
    /// Colour overrides as (ornament, part, colour). Every part left out keeps the
    /// design's own printed colour.
    pub colors: Vec<(u32, u16, Rgba)>,
}

impl Default for DressSpec {
    fn default() -> Self {
        DressSpec { ayah_mark: NONE, surah_header: NONE, page_frame: NONE, gap: 5.0, line_art: false, colors: vec![] }
    }
}

/// One placed outline, in page units.
#[derive(Clone, Copy, Debug, Default, PartialEq)]
#[repr(C)]
pub struct OrnamentDraw {
    pub op_start: u32,
    pub op_count: u32,
    pub pt_start: u32,
    pub pt_count: u32,
    pub color: Rgba,
    /// `kind | ODF_EVENODD | ODF_STROKE`
    pub flags: u32,
    /// Stroke width in page units (0 when filled).
    pub stroke_width: f32,
    /// Index into [`Ornament::parts`].
    pub part: u32,
    /// The placement this draw is drawn under: the same index a page draw carries, into
    /// the layout's placements. Without a layout it is the printed line. [`NONE`] for
    /// the border, which is drawn in layout space with no group transform.
    pub placement: u32,
}

pub const ODF_EVENODD: u32 = 1 << 8;
pub const ODF_STROKE: u32 = 2 << 8;

/// The ornaments placed on a page, and what placing them did to the page.
#[derive(Clone, Debug, Default, PartialEq)]
pub struct Dress {
    pub ops: Vec<u8>,
    pub pts: Vec<f32>,
    pub table: Vec<OrnamentDraw>,
    /// `x, y, w, h` in page units: the page's own box, or the box the border grew it to.
    pub view_box: [f32; 4],
    pub ayah_mark: u32,
    pub surah_header: u32,
    pub page_frame: u32,
    pub n_ayah_marks: u32,
    pub n_surah_headers: u32,
    /// Repeat units tiled along the four edges (0 when the frame was stretched whole).
    pub n_frame_repeats: u32,
    /// True when the frame had no slices and was stretched whole.
    pub frame_stretched: bool,
    /// Counts up every time the display list is rebuilt: a new dress, and a layout that
    /// moved the page under the border. A host caches the raster of this layer and this
    /// is what tells it the raster is stale.
    pub revision: u32,
    /// The style rules hiding the printed rings and bands, so undressing puts them back.
    pub(crate) hidden: Vec<Handle>,
    pub(crate) set: Option<Arc<OrnamentSet>>,
    pub(crate) spec: DressSpec,
}

/// `[a c e; b d f]`, enough for everything placement needs.
#[derive(Clone, Copy, Debug)]
pub(crate) struct Tf {
    pub a: f32,
    pub b: f32,
    pub c: f32,
    pub d: f32,
    pub e: f32,
    pub f: f32,
}

impl Tf {
    pub const IDENTITY: Tf = Tf { a: 1.0, b: 0.0, c: 0.0, d: 1.0, e: 0.0, f: 0.0 };
    /// `self` applied after `o` (SVG nesting order).
    pub fn then(&self, o: &Tf) -> Tf {
        Tf {
            a: self.a * o.a + self.c * o.b,
            b: self.b * o.a + self.d * o.b,
            c: self.a * o.c + self.c * o.d,
            d: self.b * o.c + self.d * o.d,
            e: self.a * o.e + self.c * o.f + self.e,
            f: self.b * o.e + self.d * o.f + self.f,
        }
    }
    pub fn apply(&self, x: f32, y: f32) -> (f32, f32) {
        (self.a * x + self.c * y + self.e, self.b * x + self.d * y + self.f)
    }
    /// The factor a stroke width is multiplied by (SVG's rule for a non-uniform matrix).
    pub fn stroke_scale(&self) -> f32 {
        (self.a * self.d - self.b * self.c).abs().sqrt()
    }
    /// Map a viewBox onto a box, as a nested `<svg>` does. `meet` keeps the aspect and
    /// centres; otherwise the drawing is stretched.
    pub fn fit(vb: [f32; 4], x: f32, y: f32, w: f32, h: f32, meet: bool) -> Tf {
        let (vw, vh) = (if vb[2] != 0.0 { vb[2] } else { 1.0 }, if vb[3] != 0.0 { vb[3] } else { 1.0 });
        let (mut sx, mut sy) = (w / vw, h / vh);
        let (mut dx, mut dy) = (0.0, 0.0);
        if meet {
            let s = sx.min(sy);
            dx = (w - vw * s) / 2.0;
            dy = (h - vh * s) / 2.0;
            sx = s;
            sy = s;
        }
        Tf { a: sx, b: 0.0, c: 0.0, d: sy, e: x + dx - vb[0] * sx, f: y + dy - vb[1] * sy }
    }
    pub fn translate(tx: f32, ty: f32) -> Tf {
        Tf { e: tx, f: ty, ..Tf::IDENTITY }
    }
    pub fn scale(sx: f32, sy: f32) -> Tf {
        Tf { a: sx, d: sy, ..Tf::IDENTITY }
    }
}

/// One ornament's colours after the spec's overrides, and its two special parts.
struct Palette {
    colors: Vec<Rgba>,
    line: Option<u16>,
    slot: Option<u16>,
}

fn palette(o: &Ornament, index: u32, spec: &DressSpec) -> Palette {
    let mut colors: Vec<Rgba> = o.parts.iter().map(|p| p.color).collect();
    for &(oi, part, rgba) in &spec.colors {
        if oi == index {
            if let Some(slot) = colors.get_mut(part as usize) {
                *slot = rgba;
            }
        }
    }
    Palette { colors, line: o.part_index("line"), slot: o.part_index("slot") }
}

struct Builder<'a> {
    set: &'a OrnamentSet,
    line_art: bool,
    out: Dress,
}

impl<'a> Builder<'a> {
    /// Emit one asset's outlines through `tf`. `drop_slot` leaves out the transparent
    /// window, which a tiled frame must not keep.
    fn place(&mut self, asset: &Asset, pal: &Palette, kind: OrnamentKind, tf: &Tf, drop_slot: bool, placement: u32) {
        let q = self.set.quant as f32;
        let ss = tf.stroke_scale();
        for i in asset.first_path..asset.first_path + asset.n_paths {
            let Some(p) = self.set.paths.get(i as usize).copied() else { continue };
            if self.line_art && Some(p.part) != pal.line {
                continue;
            }
            if drop_slot && Some(p.part) == pal.slot {
                continue;
            }
            let color = pal.colors.get(p.part as usize).copied().unwrap_or(0);
            if color & 0xff == 0 {
                continue;
            }
            let Ok(cmds) = self.set.path_cmds(i as usize) else { continue };
            let op_start = self.out.ops.len() as u32;
            let pt_start = self.out.pts.len() as u32;
            for c in &cmds {
                let mut push = |x: i32, y: i32| {
                    let (px, py) = tf.apply(x as f32 / q, y as f32 / q);
                    self.out.pts.push(px);
                    self.out.pts.push(py);
                };
                match *c {
                    Cmd::MoveTo(x, y) => {
                        self.out.ops.push(OP_MOVE);
                        push(x, y);
                    }
                    Cmd::LineTo(x, y) => {
                        self.out.ops.push(OP_LINE);
                        push(x, y);
                    }
                    Cmd::QuadTo(x1, y1, x, y) => {
                        self.out.ops.push(OP_QUAD);
                        push(x1, y1);
                        push(x, y);
                    }
                    Cmd::CubicTo(x1, y1, x2, y2, x, y) => {
                        self.out.ops.push(OP_CUBIC);
                        push(x1, y1);
                        push(x2, y2);
                        push(x, y);
                    }
                    Cmd::Close => self.out.ops.push(OP_CLOSE),
                }
            }
            let stroke = p.flags & OPF_STROKE != 0;
            self.out.table.push(OrnamentDraw {
                op_start,
                op_count: self.out.ops.len() as u32 - op_start,
                pt_start,
                pt_count: self.out.pts.len() as u32 - pt_start,
                color,
                flags: kind as u32 | if p.flags & OPF_EVENODD != 0 { ODF_EVENODD } else { 0 } | if stroke { ODF_STROKE } else { 0 },
                stroke_width: if stroke { p.stroke_width as f32 / q * ss } else { 0.0 },
                part: p.part as u32,
                placement,
            });
        }
    }

    /// The corner keeps its shape; only the straight run repeats. Stretching one drawing
    /// to a different page is what makes the side borders fatter than the top and bottom.
    fn tile_frame(&mut self, sl: &Slices, pal: &Palette, frame_tf: &Tf, unit_w: f32, unit_h: f32) {
        let (cw, ch) = (sl.corner_w, sl.corner_h);
        let turn = sl.rotate;
        let put = |b: &mut Builder<'a>, asset: &Asset, local: Tf| {
            // the slice's own viewBox already sits at the origin at its own size
            let fit = Tf::fit(asset.view_box, 0.0, 0.0, asset.width(), asset.height(), false);
            b.place(asset, pal, OrnamentKind::PageFrame, &frame_tf.then(&local.then(&fit)), true, NONE);
        };
        put(self, &sl.corner, Tf::IDENTITY);
        put(self, &sl.corner, if turn { Tf { a: -1.0, b: 0.0, c: 0.0, d: -1.0, e: unit_w, f: ch } } else { Tf::translate(unit_w, 0.0).then(&Tf::scale(-1.0, 1.0)) });
        put(self, &sl.corner, if turn { Tf { a: -1.0, b: 0.0, c: 0.0, d: -1.0, e: cw, f: unit_h } } else { Tf::translate(0.0, unit_h).then(&Tf::scale(1.0, -1.0)) });
        put(self, &sl.corner, if turn { Tf::translate(unit_w - cw, unit_h - ch) } else { Tf { a: -1.0, b: 0.0, c: 0.0, d: -1.0, e: unit_w, f: unit_h } });
        // a whole number of repeats, each nudged to fit exactly: a part-drawn motif at the
        // end of a run is the thing the eye catches
        let run = |total: f32, u: f32| -> (u32, f32) {
            let n = ((total / u.max(f32::EPSILON)).round() as i32).max(1) as u32;
            (n, total / n as f32)
        };
        let (nh, step_h) = run(unit_w - 2.0 * cw, sl.repeat_h);
        for i in 0..nh {
            let x = cw + i as f32 * step_h;
            let k = step_h / sl.repeat_h.max(f32::EPSILON);
            put(self, &sl.edge_h, Tf::translate(x, 0.0).then(&Tf::scale(k, 1.0)));
            put(self, &sl.edge_h, Tf::translate(x, unit_h).then(&Tf::scale(k, -1.0)));
        }
        let (nv, step_v) = run(unit_h - 2.0 * ch, sl.repeat_v);
        for i in 0..nv {
            let y = ch + i as f32 * step_v;
            let k = step_v / sl.repeat_v.max(f32::EPSILON);
            put(self, &sl.edge_v, Tf::translate(0.0, y).then(&Tf::scale(1.0, k)));
            put(self, &sl.edge_v, Tf::translate(unit_w, y).then(&Tf::scale(-1.0, k)));
        }
        self.out.n_frame_repeats = (nh + nv) * 2;
    }
}

impl Page {
    /// The placement a path is drawn under: its reflow group, or its printed line.
    fn placement_of_path(&self, path: u32) -> u32 {
        match &self.layout {
            Some(l) if !l.path_group.is_empty() => l.path_group[path as usize],
            _ => self.geom.table[path as usize].line,
        }
    }

    /// The laid-out page box in page units: `(top, height)`. Without a layout that is
    /// the printed page itself.
    fn laid_page_box(&self) -> (f32, f32) {
        match &self.layout {
            Some(l) => (l.laid_top, l.laid_height),
            None => (0.0, self.height()),
        }
    }

    /// The page's viewBox: `x, y, w, h`. A dressed page's border grows it.
    pub fn view_box(&self) -> [f32; 4] {
        match &self.dress {
            Some(d) => d.view_box,
            None => [0.0, 0.0, self.width(), self.height()],
        }
    }

    pub fn dress_of(&self) -> Option<&Dress> {
        self.dress.as_ref()
    }

    /// Take the ornaments off: the printed rings and bands come back and the viewBox
    /// returns to the page's own.
    pub fn undress(&mut self) {
        if let Some(d) = self.dress.take() {
            for h in d.hidden {
                self.styles.remove(h);
            }
            self.state_dirty = true;
        }
    }

    /// How much bigger the dressed page is than the laid-out content, on each side, in
    /// viewport px through the current layout: `left, top, right, bottom`. An undressed
    /// page answers zeroes.
    pub fn dress_overflow(&self) -> (f32, f32, f32, f32) {
        let Some(d) = &self.dress else { return (0.0, 0.0, 0.0, 0.0) };
        let vb = d.view_box;
        let (scale, ox, oy, cw, ch) = match &self.layout {
            Some(l) => (l.scale, l.offset_x, l.offset_y, l.content_w, l.content_h),
            None => (1.0, 0.0, 0.0, self.width(), self.height()),
        };
        (
            (-(ox + vb[0] * scale)).max(0.0),
            (-(oy + vb[1] * scale)).max(0.0),
            (ox + (vb[0] + vb[2]) * scale - cw).max(0.0),
            (oy + (vb[1] + vb[3]) * scale - ch).max(0.0),
        )
    }

    /// Re-place the ornaments against the current layout. A layout that respaces the
    /// lines makes the page taller than it is printed, and the border goes around what
    /// is on the page, so it has to follow.
    pub(crate) fn redress(&mut self) {
        let Some(d) = self.dress.as_ref() else { return };
        let (Some(set), spec) = (d.set.clone(), d.spec.clone()) else { return };
        if let Some(mut next) = self.build_dress(&set, &spec) {
            let old = self.dress.take().unwrap();
            self.dress_revision = self.dress_revision.wrapping_add(1);
            next.hidden = old.hidden;
            next.set = Some(set);
            next.spec = spec;
            next.revision = self.dress_revision;
            self.dress = Some(next);
        }
    }

    /// Put other ornaments on this page. Returns `None`, and leaves the page undressed,
    /// when an index is out of range, names an ornament of another kind, or every index
    /// is [`NONE`]. Replaces any previous dress.
    pub fn dress(&mut self, set: &Arc<OrnamentSet>, spec: &DressSpec) -> Option<&Dress> {
        self.undress();
        let mut dress = self.build_dress(set, spec)?;
        self.dress_revision = self.dress_revision.wrapping_add(1);
        dress.revision = self.dress_revision;
        if spec.ayah_mark != NONE {
            dress.hidden.push(self.hide(Selector::Kind(PathKind::AyahMarkOrnament)));
        }
        if spec.surah_header != NONE {
            for p in self.surah_name_ornament_paths() {
                dress.hidden.push(self.hide(Selector::Path(p)));
            }
        }
        self.state_dirty = true;
        dress.set = Some(set.clone());
        dress.spec = spec.clone();
        self.dress = Some(dress);
        self.dress.as_ref()
    }

    /// Place the chosen ornaments and return the display list. Pure: it reads the page
    /// and the current layout and changes neither.
    fn build_dress(&self, set: &OrnamentSet, spec: &DressSpec) -> Option<Dress> {
        let pick = |i: u32, kind: OrnamentKind| -> Option<Option<(u32, &Ornament)>> {
            if i == NONE {
                return Some(None);
            }
            let o = set.ornaments.get(i as usize)?;
            (o.kind == kind).then_some(Some((i, o)))
        };
        let mark = pick(spec.ayah_mark, OrnamentKind::AyahMark)?;
        let header = pick(spec.surah_header, OrnamentKind::SurahHeader)?;
        let frame = pick(spec.page_frame, OrnamentKind::PageFrame)?;
        if mark.is_none() && header.is_none() && frame.is_none() {
            return None;
        }
        let pw = self.width();
        let ph = self.height();
        let (laid_top, laid_h) = self.laid_page_box();
        let mut b = Builder {
            set,
            line_art: spec.line_art,
            out: Dress { view_box: [0.0, 0.0, pw, ph], ayah_mark: spec.ayah_mark, surah_header: spec.surah_header, page_frame: spec.page_frame, ..Dress::default() },
        };
        // The text column a surah band spans: the area the border encloses once one is
        // drawn, and the page's own width otherwise. Never this page's ink: pages 1 and 2
        // hold one short surah centred in the column, and a band measured from their
        // lines would come out a third of the width it has on the other 602 pages.
        let mut column = pw;

        // The border. A frame publishes its text area as its slot. Mapping the page box
        // onto that slot makes the band thickness follow at the mushaf's own proportions:
        // one uniform scale, never a stretch to the page box. The page the border goes
        // around is the laid-out one.
        if let Some((oi, o)) = frame {
            if let Some(slot) = o.asset.slot {
                let pal = palette(o, oi, spec);
                let gap = spec.gap;
                let unit = (pw + 2.0 * gap) / slot[2].max(f32::EPSILON); // page units per frame unit
                let box_x = -gap - slot[0] * unit;
                let box_y = laid_top - gap - slot[1] * unit;
                let unit_w = o.asset.width();
                let unit_h = (laid_h + 2.0 * gap) / unit + 2.0 * slot[1];
                let (box_w, box_h) = (unit_w * unit, unit_h * unit);
                let frame_tf = Tf::fit([0.0, 0.0, unit_w, unit_h], box_x, box_y, box_w, box_h, false);
                match &o.slices {
                    Some(sl) => b.tile_frame(sl, &pal, &frame_tf, unit_w, unit_h),
                    None => {
                        b.place(&o.asset, &pal, OrnamentKind::PageFrame, &Tf::fit(o.asset.view_box, box_x, box_y, box_w, box_h, false), false, NONE);
                        b.out.frame_stretched = true;
                    }
                }
                b.out.view_box = [box_x, box_y, box_w, box_h];
                column = pw + 2.0 * gap;
            }
        }

        // The band spans the column and is centred on the printed title. The column gives
        // the width and the title gives the centre, and both are measurements. The title
        // sits in the design's own slot, which is a different point on every design.
        if let Some((oi, o)) = header {
            let pal = palette(o, oi, spec);
            let vb = o.asset.view_box;
            let (_, scy) = o.asset.slot_centre();
            let k = column.max(f32::EPSILON) / o.asset.width().max(f32::EPSILON);
            let (bw, bh) = (o.asset.width() * k, o.asset.height() * k);
            for h in self.surah_headers() {
                if h.title_x1 <= h.title_x0 || h.title_y1 <= h.title_y0 {
                    continue;
                }
                let tcx = (h.title_x0 + h.title_x1) / 2.0;
                let tcy = (h.title_y0 + h.title_y1) / 2.0;
                let x = tcx - bw / 2.0;
                let y = tcy - (scy - vb[1]) * k;
                let placement = self.placement_of_path(self.data.decorations[h.decoration as usize].first_path);
                b.place(&o.asset, &pal, OrnamentKind::SurahHeader, &Tf::fit(vb, x, y, bw, bh, false), false, placement);
                b.out.n_surah_headers += 1;
            }
        }

        // The medallion is as tall as the printed ring, keeps its aspect, and puts its
        // slot centre on the ring's centre, so the numeral sits where the design leaves
        // room for it. Only the ring is replaced; the numeral is the print's own ink.
        if let Some((oi, o)) = mark {
            let pal = palette(o, oi, spec);
            let (scx, scy) = o.asset.slot_centre();
            for m in self.ayah_marks() {
                if m.r <= 0.0 {
                    continue;
                }
                let s = 2.0 * m.r / o.asset.height().max(f32::EPSILON);
                let tf = Tf { a: s, b: 0.0, c: 0.0, d: s, e: m.cx - s * scx, f: m.cy - s * scy };
                let path = if m.ornament_path != NONE { m.ornament_path } else { self.data.decorations[m.decoration as usize].first_path };
                b.place(&o.asset, &pal, OrnamentKind::AyahMark, &tf, false, self.placement_of_path(path));
                b.out.n_ayah_marks += 1;
            }
        }
        Some(b.out)
    }
}

/// A dressed page as one standalone SVG, the way `qvp2svg` is for the page itself. The
/// ornament layer comes first so it paints behind the print, as a host must draw it.
/// Draws are written in page units with no placement, so this shows the printed layout.
pub fn dress_svg(page: &mut qvp_core::Page, dress: &qvp_core::Dress) -> String {
    use std::fmt::Write;
    let vb = dress.view_box;
    let mut s = String::with_capacity(256 * 1024);
    write!(s, "<svg xmlns=\"http://www.w3.org/2000/svg\" viewBox=\"{:.3} {:.3} {:.3} {:.3}\">", vb[0], vb[1], vb[2], vb[3]).unwrap();
    s.push_str("<g class=\"ornaments\">");
    for d in &dress.table {
        let mut path = String::new();
        let pts = &dress.pts[d.pt_start as usize..(d.pt_start + d.pt_count) as usize];
        let mut i = 0usize;
        let mut take = |n: usize, out: &mut String| {
            for k in 0..n {
                write!(out, "{}{:.3} {:.3}", if k > 0 { " " } else { "" }, pts[i + k * 2], pts[i + k * 2 + 1]).unwrap();
            }
            i += n * 2;
        };
        for op in &dress.ops[d.op_start as usize..(d.op_start + d.op_count) as usize] {
            match *op {
                qvp_format::OP_MOVE => {
                    path.push('M');
                    take(1, &mut path);
                }
                qvp_format::OP_LINE => {
                    path.push('L');
                    take(1, &mut path);
                }
                qvp_format::OP_QUAD => {
                    path.push('Q');
                    take(2, &mut path);
                }
                qvp_format::OP_CUBIC => {
                    path.push('C');
                    take(3, &mut path);
                }
                _ => path.push('Z'),
            }
        }
        let hex = format!("#{:06x}", d.color >> 8);
        write!(s, "<path d=\"{path}\"").unwrap();
        if d.flags & qvp_core::ODF_STROKE != 0 {
            write!(s, " fill=\"none\" stroke=\"{hex}\" stroke-width=\"{:.4}\" stroke-linecap=\"round\" stroke-linejoin=\"round\"", d.stroke_width).unwrap();
        } else {
            write!(s, " fill=\"{hex}\"").unwrap();
            if d.flags & qvp_core::ODF_EVENODD != 0 {
                s.push_str(" fill-rule=\"evenodd\"");
            }
        }
        s.push_str("/>");
    }
    s.push_str("</g>");
    // the print on top, with the rings the dress hid left out
    let colors = page.colors().to_vec();
    let p = page.data();
    for (i, r) in p.paths.iter().enumerate() {
        if colors[i] & 0xff == 0 {
            continue;
        }
        let Ok(cmds) = p.path_cmds(i) else { continue };
        write!(s, "<path d=\"{}\" fill=\"#231f20\"", qvp_format::svg_path_d(&cmds, p.header.quant)).unwrap();
        if r.flags & qvp_format::PF_EVENODD != 0 {
            s.push_str(" fill-rule=\"evenodd\"");
        }

- [ ] **Step 1: The API doc**

Insert before `## Atlas (cross-page)` in `docs/API.md`:

```markdown
## Dress (another mushaf's ornaments)

A page carries the King Fahd Complex's own medallions, surah bands and page furniture.
`dress` puts other ornaments on it: an ayah medallion, a surah band and a page border from
another printed mushaf or from a font, and hands back a display list to paint behind the
ink.

```js
const set = engine.loadOrnaments(await fetchBytes('ornaments.qvo'));
const marker = set.find('ayah_mark', 'font-003-regular');
const info = page.dress(set, { ayahMark: marker, surahHeader: 'mushaf-qalon', pageFrame: 'mushaf-qalon', gap: 5 });
// → {ayahMark, surahHeader, pageFrame, ayahMarks, surahHeaders, frameRepeats, frameStretched, draws, revision, viewBox, overflow}
for (const o of page.dressGeometry()) { /* {path, color, kind, evenOdd, stroke, strokeWidth, part, placement} */ }
page.undress();
```

`set.list` is every ornament the set holds: `{index, kind, lineage, style, riwayah,
hasSlices, licence, parts}`. A dress names up to one ornament per kind, as an ornament, its
index or a style name. `parts` is the design's printed palette, and `colors:
[[ornament, part, colour]]` repaints any of them; `slot` is the transparent window the
design leaves for the number, the name or the text area. `lineArt: true` keeps only the
constant-width strokes, so there is one ink.

**Every ornament is placed from a measurement**, never a fixed offset: the medallion from
the printed ring's centre and radius, with the design's slot centre on the ring centre; the
band from the surah title's box across the text column; the border from the laid-out page
box. That is why the same rules land on all 604 pages.

**Paint the display list behind the page ink.** Only the printed ring and the native band
are hidden; the numeral inside the ring is the print's own ink and stays on top. Each draw
carries a `placement`, the same index a page draw carries into the layout's placements, so
a host applies the transform it already applies to the ink: a medallion follows its word
onto its row under reflow, and a band follows its title. The border carries `null` and is
drawn in layout space. `CanvasRenderer` does all of this.

**A dressed page is bigger than its text.** `viewBox` is the page box the border grew, in
page units, and `overflow` is how far the border reaches past the laid-out content on each
side, in viewport px. Fit content plus overflow, or the border is cropped off. A new layout
re-places the dress and bumps `revision`; a host that rasterises the layer keys its cache on
that number.

**The ornaments are not part of the pages.** The data release carries an `ornaments.qvo`
of the assets whose licence is confirmed (`docs/DATA.md`). A fuller set is built from a
`quran-ws/quran-assets` checkout by `qvp-convert ornaments`. Each ornament carries its own
`licence` (`{id, status, redistributable, attribution}`) and the engine reports it so a host
can say so on screen. Read it before you publish a dressed page.
```

Update the API's list of what each wrapper binds if `docs/API.md` has one near line 79. Lint the file.
